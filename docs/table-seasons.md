# 配置表适用赛季

状态：已完成（2026-11-09，用户已确认范围边界与覆盖规则）

## 行为

- 建表必须明确选择是否支持多赛季，生成五件套和文档，缺少共享基类时补齐；已有基类不覆盖。结构写 `multi_season: true|false`。业务分页默认继承表级能力，分页可写 `multi_season: false`；枚举分页不参与。旧表未声明时保留已有 `$season` 字段行为。
- 启用分页显示“适用赛季”列，数据仍使用 `$season` 字符串；空值为通用兜底。表级声明不允许改变已有业务字段或删除原始行。
- 赛季编号为完整版本编号去掉末两位，例如 101 对应 10100–10199。之前、之后、区间都包含端点；按完整编号比较，跨剧本，开放范围自动覆盖未来版本。
- 支持通用、单赛季全部版本、指定版本、赛季/版本之前与之后、连续区间、多项/多段/混合并集、扣除指定范围。排除项转换为等价的正区间并集保存；空集非法，不得保存为空值而误变通用。
- 同一业务键允许一条通用兜底与多条互不重叠的专属行；专属命中优先。多个通用或专属范围交集非空均报错，包括尚未登记的未来赛季。业务键支持结构明确指定的联合字段；自动编号分页不能假定 id 唯一。
- 选中一行或多行，通过“设置适用赛季”修改；双击适用赛季单元格打开同一入口。范围不同显示“多种范围”。应用只替换锁定的所选源行范围，整批校验通过后作为一次撤销记录写入草稿。取消无改动；只读、插件占用、正在编辑时遵循现有保护。
- 显示自然语言摘要，保留原始表达式供核对。界面明确说明边界包含本身、跨剧本。查看和检查不得只按表达式原文判重。

## 所属与同步

配置跟随当前项目、配表目录、分支。没有 Hub 新业务数据，Mock 使用 agentd 本机示例夹具。共享解析、编辑器、检查器、建表能力同步 bit-tables；项目接线只留 bit-agent。xq-common 复用共享解析及编辑入口，已有数据不机械重写。

## 验收

Go 覆盖建表明确声明与数据隔离；示例含通用、整季、版本、开区间、重复业务键。Playwright 在 Mock 登录后覆盖建表选项、自然语言显示、单/多行设置、取消、冲突阻止、保存与撤销重做。解析测试覆盖所有包含边界、跨剧本、未来交集、并集与排除、非法/空范围及兜底。

## 边界

本工作项交付表级多赛季声明及行适用范围维护；全局赛季浏览器、正式多赛季产物编排另行接入。自定义导出器的产物结构仍由各表负责，共享选择函数供其复用，不代替业务导出器。

## 范围示例

| 显示含义 | 兼容存储示例 |
| --- | --- |
| 通用兜底 | 空字符串或省略 `$season` |
| 所有 101 赛季版本 | `[10100]` |
| 所有 101、103 赛季版本 | `[10100,10300]` |
| 101 赛季之后（含） | `[10100~]` |
| 101 赛季之前（含） | `[~10199]` |
| 101～103 赛季全部版本 | `[10100~10399]` |
| 赛季版本 10101 | `[10101]` |
| 赛季版本 10101、10203 | `[10101,10203]` |
| 赛季版本 10101 之后（含） | `[10101~]` |
| 赛季版本 10101 之前（含） | `[~10101]` |
| 赛季版本 10101～10102 | `[10101~10102]` |
| 整季、指定版本和范围组合 | `[10100,10203,10302~]` |
| 101 全部版本，排除 10102 | `[10100~10101,10103~10199]` |

编辑器把包含条件取并集、再减去排除条件，合并相邻区间。仅排除条件表示从全部范围中扣除；这是专属范围，不是通用兜底。任何空集均禁止保存。版本 00 的精确点用等起止区间保存，以区别整赛季简写。

## 验证结果

- bit-agent：`go test ./internal/tables ./internal/agentd` 通过。
- bit-tables：`go test ./tables ./server` 通过；共享前端 TypeScript 检查通过。
- Mock Playwright：3 条范围规则测试、4 条赛季交互测试、1 条原有建表回归，共 8 条通过。
- xq-common：17 张现有表的范围检查无错误，编辑器编译通过，`node export.mjs item` 及 `npm run export-xlsx` 通过。
- 工作台与命令行导出在写产物前执行同一范围检查；旧 `export-xlsx` 空清单路径只补资源清单，不代表新多赛季产物编排已完成。

# 插件与引用

插件根据当前选中的单元格或列显示在右侧。“引用”从另一处读取值，“缩放”等插件在来源上执行计算；`sheet_demo` 还提供只匹配强度字段的专属插件。

## 建立绑定

1. 在普通配置表中选择目标单元格或整列。
2. 打开右侧“插件”，展开匹配的插件。
3. 点击来源旁的“更改”。
4. 切换到普通表或 Excel，选择单元格、区域或整列。
5. 点击“完成”，核对预览后激活或应用。

绑定关系写入 `<表ID>_plugins.yaml`，计算出的普通值写入 `_data.yaml`。因此保存后仍可审阅实际数值，也能追踪它来自哪里。

## 更改与解除

点击“选中”跳到当前来源，点击“更改”重新选择；“解除绑定”只移除绑定，不自动清空已经算出的值。一个目标只能有一个插件，整列绑定会替换该列已有的单元格绑定。

## 复制引用

选中后使用“复制引用”或 `Ctrl/Cmd+Shift+C`，可得到 `表.sheet!字段[行ID]`、整列或区域引用。把引用交给 AI 时，同时说明期望读取还是修改，避免只给坐标没有任务。

# 工作台界面

<DemoFigure src="/demos/navigation.png" alt="bit-tables 工作台文件搜索与编辑区域" caption="左侧搜索文件，中间编辑当前表，底部切换 Sheet，右侧查看规则与历史。" />

## 左侧文件树

搜索框按表名、ID 和路径过滤。普通目录可展开，配置表会显示完整度与检查错误。`Ctrl/Cmd+P` 可以在不移动鼠标的情况下搜索并打开任意表。

## 中间编辑区

每张打开的表都有独立标签页。底部 Sheet 栏同时列出普通 Sheet 和该表目录中的 Excel 工作表；带 Excel 图标的页面只读。

## 右侧说明区

- **结构**：展示字段与 Sheet 说明。
- **检查规则**：说明保存和检查时执行的业务规则。
- **导出规则**：区分客户端与服务端产物。
- **插件**：跟随当前选中的单元格或列。
- **历史记录**：查看 Git 或 SVN 提交。

## 查找与日志

按 `Ctrl/Cmd+F` 在当前 Sheet 或全部 Sheet 中搜索内容，选择结果会定位并高亮单元格。底部状态栏记录打开、保存、检查和导出结果；按 `Ctrl+\`` 展开或收起，清除只影响当前内存日志。

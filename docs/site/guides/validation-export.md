# 检查与导出

## 检查

保存当前表时会运行它自己的检查器。“检查 → 检查当前配置表”适合确认正在编辑的表；提交前使用“检查所有配置表”，避免遗漏依赖表。

<DemoFigure src="/demos/check-menu.png" alt="bit-tables 检查菜单中的当前表与全部表入口" caption="日常编辑检查当前表，提交或交付前检查所有配置表。" />

检查器会一次返回所有错误。有错误的表在左侧标记，编辑器中对应单元格变红；使用“下一个错误”逐项定位。不要为了通过检查而删除规则，应按右侧“检查规则”理解业务约束。

## 导出

“导出当前表”会同时导出所有直接或间接依赖它的下游表；“导出所有”会运行全部具有导出脚本的表。每张表自行定义格式，工作台只负责执行和汇总。

<DemoFigure src="/demos/export-result.png" alt="bit-tables 导出完成后的客户端和服务端目录" caption="导出结果分写到项目根目录下的 build/client 与 build/server。" />

默认输出位置：

```text
项目根目录/
  build/client/   客户端文件
  build/server/   服务端文件
```

Excel 来源不会直接导出；插件已经写回 `_data.yaml` 的值会按当前表规则进入产物。导出前先保存并检查，导出后核对对话框中的文件数与目标目录。

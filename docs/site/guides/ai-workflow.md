# 使用 AI 修改配表

bit-tables 的文件都是文本，适合让 AI 读取和修改。关键是先说清任务属于“只改数据”还是“改结构/规则”。

## 只改数据

可以这样描述：

```text
只修改 demo/tables/sheet_demo/sheet_demo_data.yaml：
把道具 iron_sword 的堆叠上限改为 2。
不要修改结构、编辑器、检查器和导出器；完成后核对文档并运行检查。
```

完成后在工作台打开对应 Sheet，检查值、枚举显示和错误标记，再保存或提交。

## 改字段或新建表

先让 AI 给出计划，确认后再执行。要求它同步结构、编辑器、检查器、导出器和 `_docs.md`，并说明是否需要迁移旧数据。新表 ID 与 Sheet ID 使用小写字母、数字和下划线。

## 解决冲突

不要让 AI 直接选择“全部保留某一方”。应同时提供冲突片段、表结构和业务目标，让它按行 ID 合并 `_data.yaml`，再用工作台检查全部表。结构或规则冲突需要逐文件核对，并同步文档。

## 提交前清单

1. 查看版本管理差异，确认没有改到无关表。
2. 打开受影响的表和下游表进行人工校对。
3. 运行“检查所有配置表”。
4. 执行对应导出并核对客户端、服务端产物。

# 编辑、填充与批量操作

## 基本编辑

表格默认用于浏览，双击单元格进入编辑。不同字段会显示数字输入、复选框、滑条、枚举下拉、多选、日期、图标或参数弹窗。修改只进入当前草稿，点击“保存”或按 `Ctrl/Cmd+S` 才会写入 `_data.yaml`。

<DemoFigure src="/demos/editing-fill.gif" alt="在 fill_demo 中选择单元格并向下填充后撤销" caption="演示在临时副本的 fill_demo 中执行填充，再用撤销恢复。" />

## 选择与复制

- 单击单元格选择一个位置。
- 拖拽可以框选矩形区域。
- 单击表头选择整列，单击行首选择整行。
- `Ctrl/Cmd+C` 与 `Ctrl/Cmd+V` 复制粘贴值。
- `Ctrl/Cmd+Shift+C` 复制可供 AI 或插件识别的表引用。

## 向下填充

选区右下角会出现填充柄。拖动填充柄可覆盖当前页的连续目标；双击填充柄会跨后续分页填充筛选结果。数值序列和插件引用会按来源行移动，任何来源越界、循环或计算失败都会取消整次操作。

<DemoFigure src="/demos/editing-toolbar.png" alt="fill_demo 的选区、填充柄和编辑工具栏" caption="红框标出选区右下角填充柄；工具栏可复制引用、撤销、重做和保存。" />

## 批量修改

勾选多行后点击“批量修改”，选择字段并输入新值。批量删除会先要求确认。操作后先检查选中行，再保存；发现范围不对可用 `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Y` 或 `Ctrl/Cmd+Shift+Z` 重做。

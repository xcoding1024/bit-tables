# 历史记录

右侧“历史记录”读取当前目录所在 Git 或 SVN 仓库的提交记录。它不会创建提交，也不会自动上传文件。

## 查看改动类型

历史记录可以按结构、检查规则、导出规则和数值修改筛选。每条记录显示作者、时间和提交说明，帮助判断某个数值或规则从何时开始生效。

## 看不到历史时

- 确认打开的是已经检出或克隆的项目目录，而不是复制出来的无版本信息文件夹。
- Git 项目需要上级目录中存在 `.git`；SVN 项目需要有效的 `.svn` 工作副本。
- 新建但尚未提交的文件不会出现在提交历史中，应通过外部 Git/SVN 客户端查看本地差异。

## 恢复旧数据

历史面板用于查看，不直接回滚。需要恢复时先保存当前工作副本，再使用团队约定的 Git/SVN 工具恢复目标版本；完成后回到工作台确认文件变更已自动刷新，并重新检查配置表。

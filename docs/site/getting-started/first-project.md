# 打开第一个项目

## 使用内置示例

首次学习建议点击“创建示例项目”，选择一个空目录。创建完成后的项目包含：

```text
demo-project/
  tables/    配置表
  src/       共享编辑、检查、导出组件与插件
  res/       图标等资源
```

若你从源码仓库运行，直接打开仓库内的 `demo` 项目根目录即可。工作台实际绑定的是其中的 `demo/tables`。

## 完成首次检查

1. 在左侧打开“Sheet 控件演示表”。
2. 在底部切换“道具”“礼包”“分类”三个 Sheet。
3. 打开“图表演示表”，切换折线图、柱状图和饼图。
4. 按 `Ctrl/Cmd+P` 搜索并打开“填充演示表”。
5. 打开右侧“结构”“检查规则”“导出规则”页签，确认每张表的说明不同。

## 打开自己的项目

自己的项目至少需要一个 `tables` 子目录。只有包含 `<表ID>_struct.yaml` 的目录会被识别为配置表；普通目录仍会显示在左侧文件树中，便于按模块整理。

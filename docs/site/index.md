# bit-tables 教程

bit-tables 是本机配表工作台。它把表结构、数据、编辑方式、检查规则、导出规则和说明文档放在普通文本文件中，既适合人工编辑，也适合 AI 协作。

## 教程使用的示例

本站所有画面和操作只使用 bit-tables 仓库自带的 `demo` 示例项目。教程中的修改在临时副本内完成，不会改动 `demo/tables` 原始数据。

- `sheet_demo`：道具、礼包、分类、多 Sheet、控件、Excel 与插件。
- `chart_demo`：折线图、柱状图和饼图编辑器。
- `enum_demo`：跨表稀有度与标签枚举。
- `fill_demo`：300 行数据、跨页填充和引用插件。
- `fill_source`：填充操作使用的普通跨表来源。

第一次使用请从 [安装与启动](/getting-started/installation) 开始。

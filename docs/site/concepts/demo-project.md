# 示例项目

## 示例表对照

| 表 | 用途 | 建议先看 |
| --- | --- | --- |
| `sheet_demo` | 多 Sheet、表格/卡片视图、图标、筛选、批量操作、Excel、插件 | 道具与礼包的不同编辑方式 |
| `chart_demo` | 自定义图表编辑器 | 同一份数据如何用折线、柱状、饼图校对 |
| `enum_demo` | 本表与跨表枚举 | 稀有度、标签如何被其他表引用 |
| `fill_demo` | 300 行分页、向下填充、引用随行移动 | 选区右下角填充柄 |
| `fill_source` | 普通跨表来源 | 填充插件如何读取另一张表 |

## 示例资源

`demo/res/item_icons` 是 `sheet_demo` 的道具与礼包图标。图标路径由结构中的模板计算，不写进每一行数据。`demo/src` 提供示例表共享的编辑器、检查器、导出器和通用插件。

## 可以放心练习

教程录制和自动化验收都会先复制整个 `demo` 到系统临时目录，再进行编辑、保存、检查和导出。日常练习也建议复制一份示例项目，避免把实验改动混入源码仓库。

# 快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 打开文件 | `Ctrl+P` | `Cmd+P` |
| 在当前表查找 | `Ctrl+F` | `Cmd+F` |
| 保存 | `Ctrl+S` | `Cmd+S` |
| 撤销 | `Ctrl+Z` | `Cmd+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` | `Cmd+Y` 或 `Cmd+Shift+Z` |
| 复制引用 | `Ctrl+Shift+C` | `Cmd+Shift+C` |
| 关闭菜单或取消高亮 | `Esc` | `Esc` |
| 展开或收起日志 | `Ctrl+\`` | `Ctrl+\`` |
| 桌面窗口切换全屏 | `F11` | `F11` |
| 桌面窗口退出全屏 | `Esc` | `Esc` |

撤销和重做只作用于当前打开的配置表编辑器。切换到另一张表后，操作的是那张表自己的草稿栈。

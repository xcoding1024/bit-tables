# 数组控件演示

## 结构

`text_integers` 与 `text_symbols` 和其它数组一样保存为 YAML 序列，分别是整数和字符串。

`integers`、`floats`、`strings` 分别保存整数、浮点数、字符串数组，`matrix` 保存嵌套整数数组，`rewards` 保存奖励对象数组。空值使用 `[]`，字符串保留空串、逗号和空白，数值以 YAML 数值保存。

双击单元格或在卡片中点击编辑，可新增、删除、上移、下移数组项；确定写回，取消或 Escape 放弃草稿。支持批量修改。表编辑器重写 `arrayItemOptions`，可用 `mount(host, context)` 挂载自定义子控件，返回 `validate` 和 `destroy`；嵌套数组递归使用同一扩展点。

## 检查规则

标识必填且唯一。整数为 JavaScript 安全整数，浮点数为有限数，字符串项保持字符串；嵌套数组逐层检查。奖励名称非空，数量为非负安全整数。自定义对象的业务校验由表检查器负责。

## 导出规则

客户端输出 `array_demo.json`；服务端输出 `array_demo.json`。两端均保留所有数组、嵌套数组与对象结构，以及各元素的数值或字符串类型。

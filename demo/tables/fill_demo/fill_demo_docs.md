# 向下填充演示

## 结构

- 配置页有 300 行，来源页有 320 行。配置字段覆盖文本、数值、布尔、对象和只读标识/图标；分组交替 A/B，可筛选出非连续行。
- 选区右下角可向下拖拽填充当前页，双击覆盖筛选结果的所有后续分页，内容按来源行顺序循环。
- fill_demo 的结果列第 5 行预置引用插件；fill-source.xlsx 提供 320 行的 Excel 值和缓存公式来源。

## 检查规则

- 演示表无额外业务检查。插件来源移动越界、循环或计算失败时，整次填充不应用。

## 导出规则

- 客户端导出配置数据为 fill_demo.json，服务端不生成文件。Excel 来源不参与导出。
